# Mortal Store

## Descripción

Mortal Store es un sitio web básico desarrollado como actividad de la Semana 1 y actualizado en la Semana 2 de la asignatura Desarrollo Frontend I.

El proyecto representa la página principal de una tienda de videojuegos. En esta segunda etapa se incorporan estilos CSS para mejorar su presentación visual, organización y adaptación a diferentes tamaños de pantalla.

## Continuidad del desarrollo por semanas

### Semana 01
- Creación de la estructura base en HTML.
- Encabezado, navegación, productos y contacto.
- Incorporación de imágenes.

### Semana 02
- Incorporación de una hoja CSS externa.
- Aplicación del modelo de cajas.
- Uso de colores y tipografías.
- Uso de selectores de clase, ID y pseudo-clases.
- Implementación de `:nth-child()`.
- Diseño responsivo mediante media queries.

## Contenido del sitio

La página incluye:

- Cabecera con el nombre y descripción de la tienda.
- Menú de navegación con enlaces a Inicio, Productos y Contacto.
- Sección de productos destacados.
- Imágenes y descripciones de videojuegos.
- Pie de página con información de contacto y redes sociales.
- Diseño responsivo para diferentes tamaños de pantalla.

## Tecnologías utilizadas
